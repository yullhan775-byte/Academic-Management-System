## Assignment Brief

A Java desktop application for APU that manages the assessment and feedback process between lecturers and students, supporting four user roles.

## My Individual Contribution

LECTURER:
	Edit personal / individual profile. 
	Design assessment types.
	Key-in assessment marks.
	Provide feedback for each assessment type.

## Key Restrictions & Requirements

The following constraints were imposed by the assignment brief — some design decisions were made specifically to meet these requirements:

1. **GUI only use libraries in java.awt and java.swing packages**

2. **Database tools are not allowed** — Tools like access, oracle, sql servers, etc. are not allowed. All data must be stored in `.txt` files.

3. **Use txt files for storing and retrieving data** — Only text files are allowed for storing and retrieving data.

4. **Use OOP Concepts**

5. **User input validation required**
